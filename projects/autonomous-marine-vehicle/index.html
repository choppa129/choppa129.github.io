01 / OVERVIEW

The challenge

A path that looks valid in a simulator can fail on water, where heading dynamics, actuator response, and positioning uncertainty complicate the connection between planning and motion.

For a team project building an autonomous surface vehicle, I led the RRT planning component and participated in integrating planning with a heading-control system. The team built and tested a differential-thrust boat equipped with positioning and inertial sensors.

02 / MY WORK

What I contributed

  • ↗Developed the RRT-based path planner in Python, including path refinement and parameter tuning.
  • ↗Participated in integration with the team's guidance and PID-based tracking workflow.
  • ↗Helped evaluate navigation runs and tune behavior using path deviation, time, and trajectory metrics.
  • ↗Contributed to iterative field validation across 13 on-water test runs.
03 / APPROACH

How the system works

01

Plan

Create a collision-aware route from map obstacles with a sampling-based RRT planner.

02

Track

Convert the planned route into a heading reference and generate control commands through the team's tracking controller.

03

Validate

Run water tests, measure deviations, and refine planning/control settings.
