# Xue Jiang — Robotics Portfolio

English-language robotics research and engineering portfolio hosted on GitHub Pages. Clean academic editorial typography, dedicated engineering case studies, and **no AI-generated imagery**. Project visuals are intentionally text-only until authentic photos or videos are added with permission.

## Live site

https://choppa129.github.io/

## Site contents

- A responsive homepage about robotics research, engineering projects, education, and experience.
- Five project pages: lab automation, video-to-simulation, radar-camera fusion, autonomous surface vehicle navigation, and toroidal propeller design.
- Links to publicly available project code, along with SEO metadata, a sitemap, and accessible mobile navigation.

## Editing

Update the structured project descriptions in `projects.json`, or the homepage markup in `tools/build.py`. Then run `python tools/build.py` to rebuild the HTML pages and commit the generated files. Edit colors, spacing and typography in `assets/style.css`. No JavaScript framework or package manager is required.

Preview locally with `python -m http.server 8000` and visit http://localhost:8000.

## Deployment

Repository: `choppa129/choppa129.github.io`. Enable **Settings → Pages → Deploy from a branch → main / (root)**. GitHub Pages will serve `index.html` at the repository root.

## Media and research notes

The initial site does not use AI-generated illustrations or claim generated visuals are real project footage. Add only genuine project photos/videos you own or are authorized to publish. The two ongoing research case studies intentionally exclude private datasets and unpublished lab artifacts. A résumé PDF is not included until it has been supplied for publication.
